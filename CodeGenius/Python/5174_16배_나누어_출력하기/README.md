# 16배 나누어 출력하기

## 문제 설명

정수 A가 입력될 때 A를 16으로 나눈 몫을 출력하는 프로그램을 작성하세요.


## 입력

첫째 줄에 정수 A가 입력됩니다. (0 ≤ A ≤ 100,000,000)


## 출력

첫째 줄에 정수 A를 16으로 나눈 몫을 출력합니다.



### 예제 1

**입력**

```text
7
```

**출력**

```text
0
```


### 예제 2

**입력**

```text
100000000
```

**출력**

```text
6250000
```
